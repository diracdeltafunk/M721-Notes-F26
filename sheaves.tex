\chapter{Sheaves}

\section{Introduction}

\startlecture[Aug 25, 2026]

Functions\footnote{For now, in this introduction, we mean simply functions between sets, i.e. morphisms in $\Set$.} are arguably the most fundamental concept in mathematics. A key feature of functions is that they may be \emph{restricted}: given a function $f : X \to Y$ and a subset $X' \subseteq X$, we can produce a function
\[f|_{X'} : X' \to Y\]
defined simply by $f|_{X'}(x) = f(x)$. Equivalently, $f|_{X'}$ is the composite
\[X' \hookrightarrow X \xrightarrow{f} Y.\]
Of course, unless $X' = X$, the restriction $f|_{X'}$ holds less information than $f$ -- it no longer remembers the behavior of $f$ on the complement $X - X'$. However, the pair of functions $(f|_{X'}, f|_{X-X'})$ \emph{is} enough to recover the entire data of $f$; indeed we have
\[f(x) = \begin{cases} f|_{X'}(x) &: x \in X' \\ f|_{X-X'}(x) &: x \notin X' \end{cases}\]
for all $x \in X$. There is no more data in $f$ than what it does on $X'$ and its complement $X - X'$. This is a special case of the following more general slogan.

\begin{slogan}
    Functions are globally determined by their local behavior.
\end{slogan}

This is only a slogan, so the terms ``global'' and ``local'' (and even ``function'') here are meant to be interpreted loosely. The central aim of this chapter is to develop the understanding that functions are \emph{precisely} those things which are globally determined by their local behavior. The desired understanding is \emph{unrigorous}, i.e. we aim to develop a certain mathematical intuition for what it means to be ``globally determined by local behavior'', and an intuition for what it means that functions are precisely those mathematical objects with this property. As with any goal of this flavor, we must develop the desired intuition by instantiating it in precise theorems.

We can summarize our first example by noticing we have an isomorphism
\[\Hom(X,Y) \cong \Hom(X',Y) \times \Hom(X - X', Y)\]
for any sets $X$ and $Y$ and any subset $X' \subseteq X$. This is a special case of the universal property of coproducts, and more importantly for our purposes, it is also a special case of a \emph{sheaf condition}. We proceed by analyzing a more general situation.

Let $X'$ and $X''$ be subsets of $X$. Then, given a function $f : X \to Y$, we may form the restrictions $f|_{X'}$ and $f|_{X''}$. This gives a map
\begin{align*}
    \Hom(X, Y) & \to \Hom(X',Y) \times \Hom(X'',Y) \\
    f          & \mapsto (f|_{X'}, f|_{X''})
\end{align*}
which in general is neither injective nor surjective. However, it is easy to understand precisely the failures of both of these conditions.

\begin{proposition}\label{prop:chap:sheaves:sec:intro:injectivity of restriction maps}
    The map
    \[
        \Hom(X, Y) \to \Hom(X',Y) \times \Hom(X'',Y)
    \]
    is injective for all sets $Y$ if and only if $X' \cup X'' = X$.
\end{proposition}
\begin{proof}
    Elementary.
\end{proof}

Note that this map being injective is the same as saying that $f$ is always reconstructible from the data $(f|_{X'}, f|_{X''})$.

\begin{proposition}\label{prop:chap:sheaves:sec:intro:image of restriction maps}
    When $X = X' \cup X''$, the image of the map
    \[
        \Hom(X, Y) \to \Hom(X',Y) \times \Hom(X'',Y)
    \]
    is precisely the set
    \[
        \{(f',f'') \in \Hom(X',Y) \times \Hom(X'', Y) : f'|_{X' \cap X''} = f''|_{X' \cap X''}\}.
    \]
\end{proposition}
\begin{proof}
    Elementary.
\end{proof}

To summarize all of the above: if $X'$ and $X''$ together cover $X$, then the data of a function on $X$ is equivalent to a pair of functions (one on $X'$ and one on $X''$) which agree on the overlap $X' \cap X''$. In other words, whenever $X = X' \cup X''$, we have a pullback square

\end{proposition}

We finish with an instantiation of our main goal: to understand that functions are \emph{precisely} those things which are determined globally by their local behavior.

\begin{theorem}\label{thm:chap:sheaves:sec:intro:sheaves are representable}
    Let $\calF : \Set^\op \to \Set$ be a functor satisfying the following ``sheaf condition'':
    \begin{description}
        \item[$(\star)$] For any set $X$ and any collection of subsets $\{X_\alpha\}_\alpha$ of $X$, if $X = \bigcup_\alpha X_\alpha$ then
              \[\calF(X) \to \prod_\alpha \calF(X_\alpha) \rightrightarrows \prod_{\alpha, \beta} \calF(X_\alpha \cap X_\beta)\]
              is an equalizer diagram in $\Set$, where the maps above are given by applying $\calF$ to the inclusions (as in \Cref{prop:chap:sheaves:sec:intro:representables are sheaves}).
    \end{description}
    Then $\calF$ is representable, i.e. $\calF \cong \Hom({-},Y)$ for some set $Y$.
\end{theorem}
\begin{proof}
    Set $Y = \calF(\pt)$. We first note that $\varnothing = \bigcup \varnothing$, whence we have an equalizer diagram of the form
    \[\calF(\varnothing) \to \pt \rightrightarrows \pt,\]
    showing that $\calF(\varnothing) \cong \pt$. Here we have used the fact that $\pt$ is terminal in $\Set$ (and empty products are terminal objects).

    Now let $X$ be an arbitrary set, and write $X = \bigcup_{x \in X} \{x\}$. Then we have an equalizer diagram
    \[\calF(X) \to \prod_{x \in X} \calF(\{x\}) \rightrightarrows \prod_{x, x' \in X} \calF(\{x\} \cap \{x'\}).\]
    We note that $\calF(\{x\} \cap \{x'\}) = \calF(\varnothing) \cong \pt$ unless $x = x'$. Therefore we have an equalizer diagram of the form
    \[\calF(X) \to \prod_{x \in X} \calF(\{x\}) \rightrightarrows \prod_{x \in X} \calF(\{x\})\]
    where the two parallel arrows are equal\footnote{Check!}. We conclude that the map
    \[\calF(X) \to \prod_{x \in X} \calF(\{x\})\]
    is an isomorphism. This allows us to construct an element
    \[i \in \calF(Y) \cong \prod_{y \in Y} \calF(\{y\}) \cong \prod_{y \in Y} \calF(\pt) = \prod_{y \in Y} Y\]

\section{Sheaves on Spaces}

Now, let $X$ be a topological space. We are often interested in continuous functions on $X$. Continuous functions also have the property that they are determined globally by their local behavior: in this context, ``local'' is best interpreted as ``on an open set''. That is: a continuous function on $X$ is uniquely determined by its restrictions to the pieces of an open cover of $X$, and a collection of continuous functions on the pieces of an open cover of $X$ comes from a continuous function on $X$ if and only if the continuous functions agree on pairwise intersections of pieces of the open cover. It is important that we restrict to open subsets here! For example, consider the functions
\begin{align*}
    f_1 : (-\infty,0) & \to \RR   & f_2 : [0,\infty) & \to \RR    \\
    x                 & \mapsto 0 & x                & \mapsto 1.
\end{align*}
We see that $f_1$ and $f_2$ are continuous, and we have
\[(-\infty,0) \cup [0,\infty) = \RR \qquad \qquad (-\infty,0) \cap [0,\infty) = \varnothing,\]
but there is no continuous function $f : \RR \to \RR$ such that $f|_{(-\infty,0)} = f_1$ and $f|_{[0,\infty)} = f_2$.

So, the correct analogue of \Cref{prop:chap:sheaves:sec:intro:representables are sheaves} for continuous functions is the following.
\begin{proposition}\label{prop:chap:sheaves:sec:spaces:representables are sheaves}
    Let $X$ and $Y$ be topological spaces, and let $\{U_\alpha\}_\alpha$ be an open cover of $X$. Then there is an equalizer diagram
    \[\Hom(X, Y) \to \prod_\alpha \Hom(U_\alpha, Y) \rightrightarrows \prod_{\alpha, \beta} \Hom(U_\alpha \cap U_\beta, Y)\]
    in the category of sets. Here the two parallel arrows are defined by
    \[(f_\alpha)_\alpha \mapsto (f_\alpha |_{U_\alpha \cap U_\beta})_{\alpha,\beta}\]
    and
    \[(f_\alpha)_\alpha \mapsto (f_\beta |_{U_\alpha \cap U_\beta})_{\alpha,\beta}.\]
\end{proposition}
\begin{proof}
    Exercise.
\end{proof}

We note that the analogue of \Cref{thm:chap:sheaves:sec:intro:sheaves are representable} does not hold in this context!

\begin{example}\label{example:chap:sheaves:sec:spaces:non representable sheaf on Top}
    Let $q : [0,1] \to S^1$ be the standard quotient map. We say that a continuous function $g : X \to S^1$ is \emph{locally liftable} along $q$ if, for all $x \in X$, there exists an open neighborhood $U$ of $x$ and a continuous function $\tilde{g} : U \to [0,1]$ such that $q \circ \tilde{g} = g|_U$.

    Let $\calF : \Top^\op \to \Set$ be the subfunctor\footnote{This means simply that each $\calF(X)$ is a subset of $\Hom(X,S^1)$, and that the inclusions $\calF(X) \to \Hom(X,S^1)$ form a natural transformation (this determines what $\calF$ does to morphisms). We'll talk more about subfunctors later!} of $\Hom({-},S^1)$ defined by
    \[\calF(X) = \{g \in \Hom(X,S^1) : g~\text{is locally liftable along}~q\}.\]

    Then the following sheaf condition holds:
    \begin{description}
        \item[$(\star)$] For any space $X$ and any open cover $\{U_\alpha\}_\alpha$ of $X$,
              \[\calF(X) \to \prod_\alpha \calF(U_\alpha) \rightrightarrows \prod_{\alpha, \beta} \calF(U_\alpha \cap U_\beta)\]
              is an equalizer diagram in $\Set$.
    \end{description}
    However, $\calF$ is not representable.
    \begin{proof}
        It is left as an exercise to show that $\calF$ is a well-defined subfunctor of $\Hom({-},S^1)$ which satisfies the sheaf condition.

        Suppose for contradiction that $\calF$ is representable, and pick a space $Y$ such that $\calF \cong \Hom({-},Y)$. By the Yoneda lemma, this natural isomorphism is determined by an element $i \in \calF(Y)$, i.e. a continuous function $i : Y \to S^1$ which is locally liftable along $q$. Precisely, the Yoneda lemma tells us that the natural isomorphism $\Hom({-},Y) \to \calF$ is given by
        \begin{align*}
            \Hom(X,Y) & \to \calF(X)       \\
            f         & \mapsto i \circ f.
        \end{align*}
        The map $i$ also gives us a natural transformation $\Hom({-},Y) \to \Hom({-},S^1)$ by postcomposition. For any space $X$, we see that the composite
        \[\calF(X) \xrightarrow{\cong} \Hom(X,Y) \xrightarrow{i_*} \Hom(X,S^1)\]
        sends an element
        $g \in \calF(X)$
        first to the unique morphism
        $f \in \Hom(X,Y)$
        such that $i \circ f = g$, and then to the morphism
        $i \circ f = g \in \Hom(X,S^1)$.
        In other words, this composite is the inclusion $\calF \to \Hom({-},S^1)$. In particular, $i_* : \Hom(X,Y) \to \Hom(X,S^1)$ is injective for all spaces $X$, i.e.\ $i : Y \to S^1$ is a monomorphism\footnote{In $\Top$, monomorphisms are simply injective continuous functions.}.

        Now observe that $q$ is itself locally liftable along $q$, since $\id_{[0,1]}$ is a
        global lift. So $q \in \calF([0,1])$, i.e.\ there is a unique continuous map
        $f : [0,1] \to Y$ with $i \circ f = q$. Since $q$ is a quotient map, $i$ is also a quotient map (in particular, $i$ is surjective). We have now established that $i$ is a bijective quotient map, i.e.\ a homeomorphism. Without loss of generality, $Y = S^1$ and $i = \id_{S^1}$. Then we have $\id_{S^1} = i \in \calF(Y) = \calF(S^1)$, which is a contradiction: $\id_{S^1}$ is not locally liftable along $q$ at the basepoint
        $\ast := q(0) = q(1)$.
    \end{proof}
\end{example}

\begin{remark*}[For experts! This remark can be safely skipped.]
    There's actually a lot going on in the background with this example. \Cref{thm:chap:sheaves:sec:intro:sheaves are representable} is stated in a strange way. The more general fact is that for any site $(\catC,\tau)$, we have
    \[\Sh(\catC,\tau) \simeq \Sh(\Sh(\catC,\tau),\mathrm{can})\]
    via the Yoneda embedding. \Cref{thm:chap:sheaves:sec:intro:sheaves are representable} is an instantiation of this in the case that $\catC = \ast$ is the terminal category (via $\Sh(\ast) \simeq \Set$), but the statement there is a priori stronger, because we only posit the sheaf condition for literal coverings by subsets $X = \bigcup_{\alpha} X_\alpha$. This turns out to not make a difference, because the canonical topology on $\Set$ is generated by these coverings. So, for $\Top$, there are two reasons to expect an example like \Cref{example:chap:sheaves:sec:spaces:non representable sheaf on Top}:
    \begin{enumerate}
        \item $\Top$ is not a Grothendieck topos (this is the real sticking point).
        \item The canonical topology on $\Top$ is not generated by open covers.
    \end{enumerate}
\end{remark*}

We can alleviate a lot of this weirdness by focusing our attention on just one topological space, instead of the entire category $\Top$. First, some theory.

\begin{definition}
    Let $X$ be a topological space. We denote by $\Open(X)$ the poset of open subsets of $X$, which we view as a category.
\end{definition}

\begin{definition}
    For any categories $\catC$ and $\catD$, a \emph{presheaf} on $\catC$ valued in $\catD$ is a functor $\calF : \catC^\op \to \catD$. The category of presheaves will be denoted $\PSh(\catC,\catD) = \Fun(\catC^\op, \catD)$.

    A \emph{presheaf} on a space $X$ valued in $\catD$ is a functor $\calF : \Open(X)^\op \to \catD$, i.e. $\PSh(X, \catD)$ is defined to be $\PSh(\Open(X), \catD)$.

    When $\catD$ is unspecified, it is assumed to be $\Set$. For example, when $X$ is a space, $\PSh(X)$ denotes the functor category $\Fun(\Open(X)^\op, \Set)$.
\end{definition}

We think of a presheaf $\calF \in \PSh(X,\catD)$ as a way of assigning, to each open subset $U \subseteq X$, a collection of data (an object of $\catD$) defined locally on $U$. As we have already seen, \emph{representable} presheaves are very important. These are intimately connected to the Yoneda lemma and its corollaries.

\begin{proposition}[Yoneda]\label{prop:Yoneda}
    Let $\catC$ be any category.
    \begin{enumerate}
        \item There is a fully faithful functor $y : \catC \to \PSh(\catC)$ (the \emph{Yoneda embedding}) defined on objects by
              \[y(X) = \Hom_\catC({-},X)\]
              and acting on morphisms by postcomposition. Presheaves $\calF \in \PSh(\catC)$ which lie in the essential image of $y$ (i.e. $\calF \cong y(X)$ for some $X$) are called \emph{representable}.
        \item There is an isomorphism
              \[\Hom_{\PSh(\catC)}(y(X),\calF) \cong \calF(X)\]
              natural in both $X$ and $\calF$. In one direction, a natural transformation $\alpha : y(X) \to \calF$ determines an element $\alpha_X(\id_X) \in \calF(X)$. In the other direction, an element $x \in \calF(X)$ determines a natural transformation $\alpha : y(X) \to \calF$ whose components are given by $\alpha_Y(f) = \calF(f)(x)$.
        \item $y$ exhibits $\PSh(\catC)$ as the free cocompletion of $\catC$. That is: $\PSh(\catC)$ is cocomplete, and any functor $F : \catC \to \catD$ with $\catD$ cocomplete factors uniquely (up to natural isomorphism) as $G \circ y$ with $G : \PSh(\catC) \to \catD$ cocontinuous.
        \item Every presheaf $\calF \in \PSh(\catC)$ is a colimit (in a canonical way) of representable presheaves. Explicitly, let $\int \calF$ (the \emph{category of elements} of $\calF$) be the category whose objects are pairs $(X,x)$ where $X \in \catC$ and $x \in \calF(X)$ -- morphisms $(X,x) \to (Y,y)$ in $\int \calF$ are morphisms $f : X \to Y$ in $\catC$ such that $\calF(f)(y) = x$. There is a projection $\pi : \int \calF \to \catC$ given by $(X,x) \mapsto X$. Composing this projection with the Yoneda embedding gives a functor $y \circ \pi : \int \calF \to \PSh(\catC)$. For each $(X,x) \in \int \calF$, there is a natural transformation $(y \circ \pi)(X,x) = y(X) \to \calF$ corresponding to the element $x \in \calF(X)$. This collection of natural transformations exhibits $\calF$ as the colimit of $y \circ \pi$.
    \end{enumerate}
\end{proposition}

\begin{example}\label{example:chap:sheaves:sec:spaces:examples of presheaves}
    Here are some examples of presheaves on spaces.
    \begin{enumerate}
        \item Let $X$ and $Y$ be spaces. There is a presheaf $\calF \in \PSh(X)$ defined by $\calF(U) = \Hom_\Top(U,Y)$. This is the composition of the representable presheaf $y(Y) : \Top^\op \to \Set$ with the (usually non-full!) inclusion $\Open(X)^\op \subseteq \Top^\op$.
        \item Let $X$ be a space and let $Y$ be a set. There is a presheaf $\calF \in \PSh(X)$ defined by $\calF(U) = Y$ for all $U \in \Open(X)$. This is a constant functor.
        \item Let $X$ be a space and let $V \in \Open(X)$. There is a presheaf $\calF \in \PSh(X)$ defined by $\calF(U) = \Hom_{\Open(X)}(U,V)$. This is the representable presheaf $y(V)$.
        \item Let $X$ be a smooth manifold, so that every open subset of $X$ is also a smooth manifold in a canonical way. There is a presheaf $\calF \in \PSh(X)$ defined by $\calF(U) = \Hom_{\Man}(U,\RR)$, where $\Man$ is the category of smooth manifolds. This is the composition of the representable presheaf $y(\RR) : \Man^\op \to \Set$ with the (usually non-full!) inclusion $\Open(X)^\op \subseteq \Man^\op$.
    \end{enumerate}
\end{example}

There are many, many more examples, but we must focus on something to start! Now we can turn to the sheaf condition for presheaves on spaces. It is precisely the generalization of the condition in \Cref{prop:chap:sheaves:sec:spaces:representables are sheaves}.

\begin{definition}
    Let $X$ be a space. A presheaf $\calF \in \PSh(X)$ is a \emph{sheaf} if for any open set $U \subseteq X$ and any open cover $\{U_\alpha\}_\alpha$ of $U$, the diagram
    \[\calF(U) \to \prod_\alpha \calF(U_\alpha) \rightrightarrows \prod_{\alpha, \beta} \calF(U_\alpha \cap U_\beta)\]
    is an equalizer diagram in $\Set$. The category of sheaves on $X$ (the full subcategory of $\PSh(X)$ spanned by all sheaves) will be denoted $\Sh(X)$.
\end{definition}

Defining sheaves with values in a generic category $\catD$ is quite subtle, philosophically. For now, we will handle only the case of ``algebraic categories''\footnote{This is intentionally imprecise, so as to avoid technical details.}, by which I mean $\Set$, $\Grp$, $\Ab$, $\Ring$, and $\CRing$. In this case, the same definition makes sense, and is ``correct''.

\begin{warning}
    We will carry this definition of ``algebraic category'' throughout this section of the notes. It is extremely nonstandard and should not be taken seriously. The point is just that these particular categories $\Set$, $\Grp$, $\Ab$, $\Ring$, $\CRing$ are very well-behaved \emph{and} it is very important to consider sheaves with values in these categories.
\end{warning}

\begin{definition}\label{def:chap:sheaves:sec:spaces:sheaf with values in algebraic category}
    Let $X$ be a space and let $\catD$ be an algebraic category. A presheaf $\calF \in \PSh(X,\catD)$ is a \emph{sheaf} if for any open set $U \subseteq X$ and any open cover $\{U_\alpha\}_\alpha$ of $U$, the diagram
    \[\calF(U) \to \prod_\alpha \calF(U_\alpha) \rightrightarrows \prod_{\alpha, \beta} \calF(U_\alpha \cap U_\beta)\]
    is an equalizer diagram in $\catD$. The category of sheaves on $X$ with values in $\catD$ (the full subcategory of $\PSh(X,\catD)$ spanned by all sheaves) will be denoted $\Sh(X,\catD)$.
\end{definition}

Note that, for our algebraic categories (or indeed any category $\catD$ which is monadic over $\Set$), the forgetful functor $\catD \to \Set$ preserves and creates limits, so a presheaf $\calF \in \PSh(X,\catD)$ is a sheaf if and only if the underlying presheaf of sets is a sheaf. We now turn to the most important example of a sheaf on a space.

\begin{example}\label{example:chap:sheaves:sec:spaces:sheaf of sections}
    Let $\pi : E \to X$ be a continuous function. There is a sheaf $\calS_\pi \in \Sh(X)$ defined on objects by
    \[\calS_\pi(U) = \{s \in \Hom_\Top(U,E) : \pi(s(x)) = x \text{ for all } x \in U\}\]
    and on morphisms by
    \begin{align*}
        \calS_\pi(U \subseteq V) : \calS_\pi(V) & \to \calS_\pi(U) \\
        s                                       & \mapsto s|_U.
    \end{align*}
    This is called the \emph{sheaf of sections} of $\pi$.
\end{example}

One of the central theorems of sheaf theory is that every sheaf on a space arises as the sheaf of sections of some continuous function. We will prove this later -- for now, we note that this informs some common terminology.

\begin{notation*}
    When $\calF$ is a (pre)sheaf on $X$ and $U$ is an open subset of $X$, we call the elements of $\calF(U)$ \emph{local sections} of $\calF$ over $U$. When $U = X$, we call the elements of $\calF(X)$ \emph{global sections} of $\calF$. When $U \subseteq V$ is an inclusion of open sets, the map
    \[\calF(U \subseteq V) : \calF(V) \to \calF(U)\]
    is called \emph{restriction}, and may be denoted $\res^V_U$. We may even write $s|_U$ for $\res^V_U(s)$ when $s \in \calF(V)$, even when $s$ is not literally a function!
\end{notation*}

\subsection{Operations and Functors on (Pre-)Sheaves}

Whenever $\catD$ is (co)complete, i.e.\ admits all small (co)limits, the category $\PSh(\catC,\catD)$ is also (co)complete, and these (co)limits are computed pointwise. In particular, for a diagram $F : \calI \to \PSh(\catC,\catD)$ (with $\calI$ a small category), we have
\[(\lim F)(c) \cong \lim_{i \in \calI} F(i)(c) \qquad (\colim F)(c) \cong \colim_{i \in \calI} F(i)(c)\]
for all objects $c \in \catC$. In particular, we may form products, coproducts, pullbacks, equalizers, etc.\ of presheaves quite easily. The same is true for \emph{limits} of sheaves on spaces\footnote{Actually, $\Sh(X)$ is both complete and cocomplete, but the colimits are not computed pointwise. We'll get into this later.}.

\begin{proposition}\label{prop:chap:sheaves:sec:spaces:sheaves are complete}
    Let $X$ be a space and let $\catD$ be an algebraic category. Then $\Sh(X,\catD)$ is complete, and limits in $\Sh(X,\catD)$ are computed pointwise.
\end{proposition}
\begin{proof}
    Exercise.
\end{proof}

This tells us, for example, that morphisms of sheaves of abelian groups have kernels, which are computed pointwise, i.e.\ $\ker(\varphi)(U) = \ker(\varphi_U : \calF(U) \to \calF'(U))$ for any morphism $\varphi : \calF \to \calF'$ of sheaves of abelian groups and any open set $U \subseteq X$.

There are also constructions that allow us to move between different categories of (pre)sheaves.

\begin{proposition}\label{prop:chap:sheaves:sec:spaces:image of presheaves and adjoints}
    Let $F : \catC \to \catC'$ be any functor, and let $\catD$ be any category. There is a functor $F^* : \PSh(\catC', \catD) \to \PSh(\catC, \catD)$ given by precomposition with $F^\op$.

    Now assume moreover that $\catC$ and $\catC'$ are small.
    \begin{enumerate}[label=(\roman*)]
        \item If $\catD$ is cocomplete, then $F^*$ admits a left adjoint $F_! : \PSh(\catC, \catD) \to \PSh(\catC', \catD)$ defined by
              \[(F_! \calF)(c') = \colim_{(c,u) \in (c' \downarrow F)^\op} \calF(c).\]
        \item If $\catD$ is complete, then $F^*$ admits a right adjoint $F_* : \PSh(\catC, \catD) \to \PSh(\catC', \catD)$ defined by
              \[(F_* \calF)(c') = \lim_{(c,u) \in (F \downarrow c')^\op} \calF(c).\]
    \end{enumerate}
\end{proposition}
\begin{proof}
    Exercise for experts.
\end{proof}

This proposition is stated in large generality so that we can use it in other contexts later -- it is not necessary to fully understand the definitions of $F_!$ and $F_*$; we only need to know they exist\footnote{Also, $F_*$ almost never appears in practice.}. For now, we only need the functors $F^*$ and $F_!$ in the special case that $F = f^{-1} : \Open(Y) \to \Open(X)$, where $f : X \to Y$ is a continuous map between spaces.

\begin{corollary}\label{cor:chap:sheaves:sec:spaces:image of presheaves on spaces and adjoints}
    Let $f : X \to Y$ be a continuous map of spaces, and let $\catD$ be a category which admits all filtered colimits\footnote{For example, any algebraic category. \Cref{prop:chap:sheaves:sec:spaces:image of presheaves and adjoints} asks that $\catD$ admit all colimits, but filtered colimits suffice for this corollary.}. Then $f^{-1} : \Open(Y) \to \Open(X)$ is a functor between small categories, and we obtain an adjunction\footnote{It's worth acknowledging that this notation is very confusing.}

    \[\begin{tikzcd}
            {\PSh(X,\catD)} \\
            {\PSh(Y,\catD)}
            \arrow[""{name=0, anchor=center, inner sep=0}, "{f_* := (f^{-1})^*}", shift left=3, from=1-1, to=2-1]
            \arrow[""{name=1, anchor=center, inner sep=0}, "{(f^{-1})_! =: f^{-1}_\mathrm{pre}}", shift left=3, from=2-1, to=1-1]

        \end{tikzcd}\]
    (the left adjoint is written on the left-hand side). These functors are given on objects by
    \[(f_* \calF)(V) = \calF(f^{-1}(V))\]
    and
    \[(f^{-1}_\mathrm{pre} \calF)(U) = \colim_{V \supseteq f(U)} \calF(V).\]

Note that if $f(U)$ is open in $Y$, then $(f^{-1}_\mathrm{pre} \calF)(U) = \calF(f(U))$. It is clear from the definitions that these constructions are (pseudo)functorial: for any composable pair of continuous maps $X \xrightarrow{f} Y \xrightarrow{g} Z$, we have
\[(g \circ f)_* = g_* \circ f_*\]
and it follows that
\[(g \circ f)^{-1}_\mathrm{pre} \cong f^{-1}_\mathrm{pre} \circ g^{-1}_\mathrm{pre}.\]

As a special case, we may consider the inclusion of a point $x \in X$, which we will denote $i_x : \pt \to X$.

\begin{definition}
    Let $\catD$ be a category admitting all filtered colimits. For any space $X$ and any point $x \in X$, we define the \emph{stalk} of a presheaf $\calF \in \PSh(X,\catD)$ at $x$ to be the global sections of the presheaf $(i_x)^{-1}_\mathrm{pre}(\calF)$, i.e.
    \[\calF_x := (i_x)^{-1}_\mathrm{pre} (\calF)(\pt) = \colim_{U \ni x} \calF(U).\]
    This yields the \emph{stalk functor} $\calF \mapsto \calF_x :\PSh(X,\catD) \to \catD$.
\end{definition}

Stalks are very important invariants of a (pre)sheaf. In nice cases, filtered colimits in $\catD$ commute with finite limits, so the stalk functor preserves finite limits. We record this briefly since it is often useful.

\begin{proposition}\label{prop:chap:sheaves:sec:spaces:stalk functor preserves finite limits}
    Let $\catD$ be an algebraic category. Then $f^{-1}_\mathrm{pre} : \PSh(Y,\catD) \to \PSh(X,\catD)$ preserves finite limits for any continuous map $f$, and in particular the stalk functor $\calF \mapsto \calF_x : \PSh(X,\catD) \to \catD$ preserves finite limits for any point $x \in X$.
\end{proposition}
\begin{proof}
    Abstract nonsense.
\end{proof}

\begin{definition}
    If $U \subseteq X$ is an open set containing a point $x$, then $U$ is one of the open sets indexing the colimit defining the stalk $\calF_x$, and so we have a canonical map
    \[\calF(U) \to \calF_x\]
    which is natural in $\calF$.

    When $\catD$ is one of our algebraic categories\footnote{Note that all of our algebraic categories are concrete, i.e. objects in $\catD$ have underlying sets and therefore elements.}, we write $s \mapsto s_x$ for the action of this map. We call $s_x$ the \emph{germ}\footnote{All of the terminology here is agricultural. A sheaf is a collected bundle of stalks of (e.g.) wheat, and each stalk of wheat has many germs (basically, the seeds/grains at the end of the stalk).} of the section $s$ at $x$.
\end{definition}

Intuitively, if we think of $s$ as some kind of function locally defined on $U$, its germ $s_x$ remembers only the behavior of $s$ at points ``arbitrarily close'' to $x$.

\begin{proposition}\label{prop:chap:sheaves:sec:spaces:same germ means same locally}
    Let $s, t \in \calF(U)$ be local sections of a presheaf $\calF \in \PSh(X,\catD)$, where $\catD$ is algebraic. Let $x \in U$. We have $s_x = t_x$ in $\calF_x$ if and only if there is some open neighborhood $V$ of $x$ such that $V \subseteq U$ and $s|_V = t|_V$.
\end{proposition}
\begin{proof}
    Exercise (this just boils down to how colimits are constructed in our algebraic categories).
\end{proof}

In fact, the above proposition can be generalized: we can take $s \in \calF(U)$ and $t \in \calF(U')$ for any two open sets $U, U' \subseteq X$ containing $x$, and find that $s_x = t_x$ if and only if there is some open neighborhood $V \subseteq U \cap U'$ of $x$ such that $s|_V = t|_V$. In particular, note that $(s|_V)_x = s_x$ whenever $x \in V \subseteq U$ and $s \in \calF(U)$.

We finish with an omnibus theorem collecting some important facts about sheaves on spaces.

\begin{theorem}\label{thm:chap:sheaves:sec:spaces:facts about sheaves}
    Let $\catD$ be an algebraic category and $X, Y$ topological spaces. Then:
    \begin{enumerate}[label=(\roman*)]
        \item For any continuous function $f : X \to Y$, the functor $f_* : \PSh(X,\catD) \to \PSh(Y,\catD)$ restricts to a functor $f_* : \Sh(X,\catD) \to \Sh(Y,\catD)$.
        \item For any point $x \in X$, the functor $(i_x)^{-1}_{\mathrm{pre}} : \PSh(X,\catD) \to \PSh(\pt, \catD)$ restricts to a functor $(i_x)^{-1}_{\mathrm{pre}} : \Sh(X,\catD) \to \Sh(\pt, \catD)$. Noting that taking global sections is an equivalence $\Sh(\pt,\catD) \to \catD$, we can view $(i_x)^{-1}_\mathrm{pre}$ as the functor sending a sheaf $\calF$ to its stalk $\calF_x \in \catD$.
        \item For any open set $U \subseteq X$ and any sheaf $\calF \in \Sh(X,\catD)$, the morphism $\calF(U) \to \prod_{x \in U} \calF_x$ given by taking germs is injective.
        \item Let $\varphi : \calF \to \calF'$ be a morphism in $\Sh(X,\catD)$. Then $\varphi$ is an isomorphism if and only if the induced morphism on stalks $\varphi_x : \calF_x \to \calF'_x$ is an isomorphism for all $x \in X$.
        \item Let $\varphi_1, \varphi_2 : \calF \to \calF'$ be morphisms in $\Sh(X,\catD)$. We have $\varphi_1 = \varphi_2$ if and only if $(\varphi_1)_x = (\varphi_2)_x$ for all $x \in X$.
    \end{enumerate}
\end{theorem}
\begin{proof}
    \begin{enumerate}[label=(\roman*)]
        \item Exercise.
        \item Exercise.
        \item Let $s, t \in \calF(U)$ be such that $s_x = t_x$ for all $x \in U$. Let $\calV$ be the collection of all open subsets $V \subseteq U$ such that $s|_V = t|_V$. Since $s_x = t_x$ for all $x \in U$, \Cref{prop:chap:sheaves:sec:spaces:same germ means same locally} tells us that $\calV$ is an open cover of $U$. Now we apply the sheaf condition: $s$ and $t$ are local sections of $\calF$ on $U$ which agree on all pieces of the open cover $\calV$, so $s = t$.
        \item If $\varphi$ is an isomorphism, then $\varphi_x$ is an isomorphism for all $x \in X$ (because the stalk functors are functors). Conversely, suppose that $\varphi_x$ is an isomorphism for all $x \in X$. Since $\catD$ is algebraic, it suffices to show that the underlying morphism of presheaves of sets is an isomorphism, i.e.\ that $\varphi_U : \calF(U) \to \calF'(U)$ is a bijection for all $U$. So, let $U \in \Open(X)$ be arbitrary. By naturality of taking germs and (iii), we have a commutative diagram

                      {\calF(U)} \& {\calF'(U)} \\
                      {\prod_{x \in U} \calF_x} \& {\prod_{x \in U} \calF'_x}
                      \arrow["{\varphi_U}", from=1-1, to=1-2]
                      \arrow[tail, from=1-1, to=2-1]
                      \arrow[tail, from=1-2, to=2-2]
                      \arrow["{\prod_{x \in U} \varphi_x}"', "\cong", from=2-1, to=2-2]
                  \end{tikzcd}\]
              showing that $\varphi_U$ is injective. To show that $\varphi_U$ is surjective, let $s' \in \calF'(U)$. For each $x \in U$, we have $s'_x \in \calF'_x$, and since $\varphi_x$ is an isomorphism, there exists a unique $a_x \in \calF_x$ such that $\varphi_x(a_x) = s'_x$. By the definition of stalks, for each $x$ there exists an open neighborhood $V_x$ of $x$ and a local section $\sigma_x \in \calF(V_x)$ such that $(\sigma_x)_x = a_x$.               for all $x \in U$. Since $\calF'$ is a sheaf and $\{W_x\}_{x \in U}$ is an open cover of $U$, we conclude that $\varphi_U(s) = s'$.
        \item Let $\psi : \calE \to \calF$ be the equalizer of $\varphi_1$ and $\varphi_2$ in $\Sh(X,\catD)$. \end{proof}

\begin{corollary}
    A sheaf $\calF$ is terminal (in the category $\Sh(X,\catD)$) if and only if $\calF_x$ is terminal in $\catD$ for all $x \in X$.
\end{corollary}
\begin{proof}
    First, note that the terminal presheaf $\ast$ (the constant functor whose value is the terminal object in $\catD$) is also the terminal object of $\Sh(X,\catD)$, by \Cref{prop:chap:sheaves:sec:spaces:sheaves are complete}. We may compute directly that $\ast_x$ is terminal in $\catD$ for all $x \in X$. Then let $\calF \in \Sh(X,\catD)$ be arbitrary. There is a unique morphism of sheaves $\calF \to \ast$, which is an isomorphism if and only if $\calF$ is terminal. By \Cref{thm:chap:sheaves:sec:spaces:facts about sheaves}, we conclude that $\calF$ is terminal if and only if $\calF_x \to \ast_x$ is an isomorphism for all $x \in X$. Since $\ast_x$ is terminal in $\catD$, this is equivalent to $\calF_x$ being terminal in $\catD$ for all $x \in X$.
\end{proof}

\begin{slogan}\label{slogan:sheaves are governed by their stalks}
    Sheaves are governed by their stalks.
\end{slogan}

\begin{remark}
    This is a good time to return to our definition of ``algebraic category''. One may wonder why we don't simply define $\Sh(X,\catD)$ for $\catD$ an arbitrary category -- our \Cref{def:chap:sheaves:sec:spaces:sheaf with values in algebraic category} makes perfect sense in general\footnote{Even if $\catD$ does not admit all equalizers, we can simply demand that each required equalizer does exist.}. There are two reasons we don't do this.
    \begin{itemize}
        \item In order to define stalks, we need $\catD$ to admit all filtered colimits.
        \item Even if $\catD$ is complete and cocomplete, so that we may define stalks and all of our nice constructions, \Cref{thm:chap:sheaves:sec:spaces:facts about sheaves}(iv) (and thus \Cref{slogan:sheaves are governed by their stalks}) may fail. See \Cref{exercise:chap:sheaves:sec:spaces:sheaves of spaces are bad} for an example.
    \end{itemize}
    Really, the only category of sheaves on $X$ that matters is $\Sh(X,\Set)$ -- sheaves with values in other categories are correctly interpreted ``internally'', i.e.\ as sheaves of sets with extra structure (see \Cref{exercise:chap:sheaves:sec:spaces:ShAb is AbSh}). For our algebraic categories, it turns out that it is equivalent to take the ``external'' definition of sheaves with values in $\catD$ or the ``internal'' definition of sheaves of sets with extra structure (and often convenient to define things in the external way).
\end{remark}

\subsection{Open Embeddings}

We have seen (in \Cref{thm:chap:sheaves:sec:spaces:facts about sheaves}) that for any continuous map $f : X \to Y$, the functor $f_* : \PSh(X,\catD) \to \PSh(Y,\catD)$ preserves sheaves. Its left adjoint $f^{-1}_\mathrm{pre}$, however, does not preserve sheaves in general (see \Cref{exercise:chap:sheaves:sec:spaces:preimage does not preserve sheaves}). However, if $f$ is an open embedding, this problem goes away.

\begin{proposition}
    Let $i : U \to X$ be an open embedding (i.e.\ $U$ is the inclusion of an open subspace of $X$). Then the functor $i^{-1}_\mathrm{pre} : \PSh(X,\catD) \to \PSh(U,\catD)$ preserves sheaves, and thus restricts to a functor $i^{-1} : \Sh(X,\catD) \to \Sh(U,\catD)$ which is left adjoint to $i_* : \Sh(U,\catD) \to \Sh(X,\catD)$.
\end{proposition}
\begin{proof}
    We may compute directly that
    \[(i^{-1}_\mathrm{pre} \calF)(V) = \colim_{W \supseteq i(V)} \calF(W) = \colim_{W \supseteq V} \calF(W) = \calF(V)\]
    for any open set $V \subseteq U$. Then sheaf condition for $\calF$ on $X$ implies the sheaf condition for $i^{-1}_\mathrm{pre} \calF$ on $U$. The adjunction follows from the fact that $\Sh(X,\catD)$ is a full subcategory of $\PSh(X,\catD)$.
\end{proof}

We often write $\calF \mapsto \calF|_U$ for the action of the functor $i^{-1} : \Sh(X,\catD) \to \Sh(U,\catD)$, and call $\calF|_U$ the \emph{restriction} of $\calF$ to $U$.

\begin{exercise}\label{exercise:chap:sheaves:sec:spaces:sheaves of spaces are bad}
    In this exercise, you will show that \Cref{thm:chap:sheaves:sec:spaces:facts about sheaves}(iv) can fail badly for sheaves valued in a category which is not algebraic, even one which is complete and cocomplete. We take $\catD = \Top$, and read \Cref{def:chap:sheaves:sec:spaces:sheaf with values in algebraic category} verbatim, with the equalizer taken in $\Top$. That is: $\calF \in \PSh(X,\Top)$ is a sheaf if, for every open set $U \subseteq X$ and every open cover $\{U_\alpha\}_\alpha$ of $U$, the map
    \[\calF(U) \to \prod_\alpha \calF(U_\alpha)\]
    is a topological embedding whose image is exactly the set of tuples agreeing on pairwise intersections.

    For an open set $U \subseteq \RR$, write $C(U)$ for the set of continuous functions $U \to \RR$. Define presheaves $\calF_k, \calF_p \in \PSh(\RR, \Top)$ by letting $\calF_k(U)$ be $C(U)$ with the compact-open topology, letting $\calF_p(U)$ be $C(U)$ with the topology of pointwise convergence, and taking the usual restriction maps in both cases.
    \begin{enumerate}[label=(\alph*)]
        \item Show that $\calF_p$ is a sheaf.\\
              \textit{Recall:} The topology of pointwise convergence on $C(U)$ is the initial topology for the collection of evaluation maps $\{\mathrm{ev}_y : C(U) \to \RR\}_{y \in U}$.
        \item Show that $\calF_k$ is a sheaf.\\
              \textit{Hint:} If $K \subseteq U$ is compact and $\{U_\alpha\}_\alpha$ covers $U$, then $K = K_1 \cup \cdots \cup K_n$ for finitely many compact sets $K_i$, each contained in some $U_{\alpha_i}$.
        \item Show that the identity maps $C(U) \to C(U)$ assemble into a morphism $\varphi : \calF_k \to \calF_p$ in $\Sh(\RR,\Top)$, and that $\varphi$ is not an isomorphism.
        \item Fix $x \in \RR$ and let $\calG_x$ denote the set of germs at $x$ of continuous real-valued functions defined near $x$. Show that $(\calF_k)_x$ and $(\calF_p)_x$ both have underlying set $\calG_x$, and that in both cases the topology on the stalk is the initial topology for the map $\calG_x \to \RR$ sending a germ to its value at $x$. Conclude that $\varphi_x$ is a homeomorphism for every $x \in \RR$.
        \item Conclude that $\varphi$ is a morphism of sheaves which is an isomorphism stalkwise, but is not an isomorphism.
    \end{enumerate}
\end{exercise}
